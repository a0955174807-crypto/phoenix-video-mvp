# Phoenix AI OS

Phoenix AI OS 是一套以「人類決策 + AI 協作 + 工具執行」為核心的個人 AI 作業系統。

## 核心理念

Phoenix AI OS 不綁定單一 AI 或工具，而是依照任務需求選擇最適合的執行方式。

基本流程：

CEO 提出目標／任務  
↓  
AI 總管分析與拆解  
↓  
風險分級與 Decision Firewall  
↓  
選擇適合的 AI／工具  
↓  
執行任務  
↓  
驗收結果  
↓  
紀錄與持續改進

## 目前使用的 AI 與工具

- ChatGPT
- Codex
- Claude Code
- GitHub
- Obsidian
- Remote Desktop Commander
- 其他可整合的 AI Agent 與自動化工具

## 核心原則

1. 實際成果優先
2. 使用最小足夠工具
3. 依任務進行風險分級
4. 低風險任務盡量自動化
5. 高風險或重要操作保留人工確認
6. 能局部驗證，不重跑整套流程
7. 能沿用既有證據，不重複工作
8. 每次實作同步累積 SOP、案例與教學資產

## Decision Firewall

Decision Firewall（決策防火牆）用來判斷 AI 任務是否可以直接執行，或需要人工確認。

主要考量：

- 是否會修改或刪除重要資料
- 是否涉及帳號、權限或安全
- 是否涉及金錢或不可逆操作
- 是否會對外發布內容
- 是否需要 CEO 最終確認

## 發展方向

Phoenix AI OS 將逐步發展：

- AI 多代理協作
- GitHub 任務派工
- Codex / Claude Code 自動執行
- Email 自動分類與整理
- LINE 訊息處理
- AI 短影音製作
- AI 微電影製作
- SOP 與 Skill 系統
- AI 教學與知識管理

## 專案狀態

目前持續開發與實際測試中。

Phoenix AI OS 的目標不是只建立一套 AI 工具，而是建立一套可以持續學習、執行、驗證與進化的人機協作系統。
